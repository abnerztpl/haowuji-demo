# 好物集 Demo

前端静态交互演示。四种角色共享一个以整数分计价的本地状态，localStorage 持久化并监听同源标签页更新。部署目录 dist，无构建依赖。

## 演示流程
工具条载入购物车（自动关联 HG001）→ 模拟支付 129.80 → 供应商谷仓食集发货 → 消费者申请苹果退款 → 平台审批退款 59.90 → 确认香米收货 → 推进等待期 → 结算佣金 6.99 与供货应付 45.00。
历史完成订单已结算，不占本流程可结算余额。其他状态样例用于展示列表。

## 范围
虚构人物及供应商；模拟支付、退款、物流与结算；无真实认证、支付或外部业务接口。每个浏览器独立演示数据，无远程数据库。

## 核验
实际浏览器走通核心全流程，核对支付、拆单、冻结、退款、收货与结算记录；测试刷新持久化、搜索、规格、后台改价和分享复制；390px iframe 视口确认商城、购物车与后台无页面横向溢出。

## 图片素材
商品图片仅为展示示意。主要摄影来自 Unsplash；毛巾图片来自 West Elm 商品示意，编织篮来自 Will & Atlas。所有素材已作为静态资源打包。品牌视觉与网页设计原创，不代表真实商品背书。

## GitHub Actions 部署

1. 仓库 Settings → Pages → Build and deployment，Source 选择 GitHub Actions。
2. Actions → Deploy Haowuji Demo → Run workflow，选择 main 并运行。
3. 完成后在运行摘要的 github-pages 环境打开网站地址。

工作流为手动触发，无需构建，发布 dist 目录。GitHub Pages 的可用性取决于仓库套餐与 Pages 设置；此仓库不自动改变可见性。国内访问效果取决于最终部署网络，Actions 本身不提供访问加速。

## 部署到其他服务器

将 dist 目录内全部文件上传到静态网站根目录即可，不需要 Node.js 或后端。图片、样式与脚本均为本地相对路径，没有海外图片接口或 CDN 依赖。

## 本地预览

在仓库根目录运行 `python -m http.server 8080 --directory dist`，然后打开 http://localhost:8080/。
